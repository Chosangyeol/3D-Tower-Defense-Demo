# 2026-11-28 — 타워 추가

## 결정
- 타워 증강과 연구는 모든 타워에 적용되는 것과 특정 타워 전용으로 나눈다
- 감속 탑: 피해 없이 일정 시간 느려지게 한다. 기본 상태는 공격 간격이 감속 시간보다 길다
- 대포: 쏜 순간의 위치에 낙하
- 새 타워의 연구와 전용 증강은 이번에 만들지 않는다

## 한 일
- 공격 방식(`TowerAttack`) 분리: 추적 탄, 낙하 포탄, 감속 파동. 수치는 타워 데이터에 모음
- 대포(목재 30·광석 40, 사거리 7, 피해 30, 2초, 폭발 반경 2, 포탄 속도 10)
- 감속 탑(목재 40·광석 20, 사거리 4, 3초마다 50% 감속 1.5초)
- 증강에 대상 타워 추가. 다연장 포탑·저격 포탑·서리 탄환은 기본 포탑 전용, 카드에 적용 대상 표시
- 선택 칸 1~3, 안내 UI에 타워 목록
- 범위 표시를 `AreaFlash`로 이름을 바꿔 폭발 마법, 대포, 감속 탑이 함께 사용
- 수치 추가: 타워 폭발 반경

## 확인한 것 (코드 호출)
- 세 타워의 비용·환급·수치, 기본 포탑의 동작 유지
- 대포의 범위 피해, 대상이 먼저 죽어도 착탄, 사거리 끝(거리 약 6)에서 일반·탱커는 맞고 빠른 적은 피하며 감속되면 맞음
- 감속 탑: 적이 있을 때만 발동, 피해 없음, 1.5초 뒤 풀리고 3초마다 다시 감속, 범위 안 전부 감속
- 전용 증강은 기본 포탑에만, 공통 증강과 대상 없는 효과는 모든 타워에 적용
- 모든 데이터 종류의 CSV 왕복 정상, 씬의 빈 참조 없음
