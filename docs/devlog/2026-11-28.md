# 2026-11-28 — 타워 추가

## 결정
- 타워 증강과 연구는 모든 타워에 적용되는 것과 특정 타워 전용으로 나눈다
- 감속 탑: 피해 없이 일정 시간 느려지게 한다. 기본 상태는 공격 간격이 감속 시간보다 길다
- 대포: 쏜 순간의 위치에 낙하
- 새 타워의 연구와 전용 증강은 이번에 만들지 않는다

## 한 일
- 공격 방식(`TowerAttack`) 분리: 추적 탄, 낙하 포탄, 감속 파동. 수치는 타워 데이터에 모음
- 대포(목재 30·광석 40, 사거리 7, 피해 30, 2초, 폭발 반경 2, 포탄 속도 10)
- 감속 탑(목재 40·광석 20, 사거리 4, 3초마다 50% 감속 1.5초)
- 증강에 대상 타워 추가. 다연장 포탑·저격 포탑·서리 탄환은 기본 포탑 전용, 카드에 적용 대상 표시
- 선택 칸 1~3, 안내 UI에 타워 목록
- 범위 표시를 `AreaFlash`로 이름을 바꿔 폭발 마법, 대포, 감속 탑이 함께 사용
- 수치 추가: 타워 폭발 반경

## 확인한 것 (코드 호출)
- 세 타워의 비용·환급·수치, 기본 포탑의 동작 유지
- 대포의 범위 피해, 대상이 먼저 죽어도 착탄, 사거리 끝(거리 약 6)에서 일반·탱커는 맞고 빠른 적은 피하며 감속되면 맞음
- 감속 탑: 적이 있을 때만 발동, 피해 없음, 1.5초 뒤 풀리고 3초마다 다시 감속, 범위 안 전부 감속
- 전용 증강은 기본 포탑에만, 공통 증강과 대상 없는 효과는 모든 타워에 적용
- 모든 데이터 종류의 CSV 왕복 정상, 씬의 빈 참조 없음

## 남은 것
- 직접 플레이로 비용·피해·간격 조정
- 새 타워의 연구와 전용 증강

# 2026-11-28 — 연구 트리

## 결정
- 연구는 선행을 마치면 다음 단계가 열리는 트리. 타워·건물·플레이어 3탭
- 처음에는 기본 포탑만 설치·연구 가능. 건물 탭에서 타워를 해금하면 설치와 전용 연구가 함께 열린다
- 특수 능력 택 1은 그 판 동안 고정
- 플레이어 탭은 능력치와 택 1
- 세부 능력치와 특수 능력은 추후 확정. 지금 설계대로 만들되 언제든 수정 가능하게 한다

## 한 일
- 연구 34개와 갈래 10개를 데이터로 생성. 기존 연구 3개는 기본 포탑 1·2단계로 옮기고 비용 변경
- `UpgradeDefinition`: 갈래, 택 1 묶음, 해금할 타워 추가. 설명을 비우면 효과에서 자동 생성
- 타워 해금: 잠긴 타워는 설치·선택 불가, 안내 UI에 "(잠김)"
- 연구 화면을 탭·트리 형태로 교체. 배치는 데이터에서 만들고 화면보다 크면 줄인다
- 잘못 고친 데이터(순환, 목록에 없는 선행 등)는 판을 시작할 때 경고
- 새 기능: 감속 중 받는 피해 증가, 감속 파동의 피해

## 확인한 것
- 코드 호출과 가상 입력: 해금, 단계 진행, 택 1, 비용, 각 효과, 탭·버튼 클릭, 화면 뒤 칸에 설치되지 않음, 다시 시작하면 초기화
- 데이터 수정: 수치를 바꾸면 설명이 따라 바뀜, 새 연구를 목록에 넣으면 화면에 나옴, CSV 왕복 정상

## 남은 것
- 직접 플레이로 비용과 수치 조정 (맵의 마력 결정맥이 1개뿐)
- 아직 해금하지 않은 타워의 전용 증강이 생기면 후보에 나올지 정하기
