# 3D 타워 디펜스

탑뷰로 타워를 배치하고, 1인칭 시점으로 타워와 함께 직접 싸우는 하이브리드 타워 디펜스 게임.

## 핵심 루프

```
마을 (업그레이드·강화) → 배치 단계 (3D 탑뷰) → 전투 단계 (1인칭) → 보상 → 마을
```

| 단계 | 시점 | 플레이어가 하는 일 |
|------|------|------------------|
| 배치 | 3D 탑뷰 | 맵을 보며 타워 설치·이동·판매 |
| 전투 | 1인칭 | 타워와 함께 웨이브를 직접 막아냄 |
| 마을 | (미정) | 타워 업그레이드, 플레이어 강화 |
