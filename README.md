## 소개

기존 타워 디펜스는 타워를 배치한 뒤 지켜보는 장르입니다.
**3D 타워 디펜스**는 배치가 끝난 뒤 플레이어가 **1인칭 시점으로 전장에 직접 들어가** 타워와 함께 적을 막아냅니다.
전투에서 얻은 보상으로 **마을**에서 타워를 업그레이드하고 플레이어를 강화합니다.

## 핵심 루프

```
 ┌──────────┐     ┌────────────────┐     ┌────────────────┐
 │   마을   │ ──▶ │  배치 (탑뷰)   │ ──▶ │ 전투 (1인칭)   │
 │ 업그레이드│     │ 타워 설치·편집 │     │ 타워와 함께 방어│
 └──────────┘     └────────────────┘     └────────────────┘
       ▲                                          │
       └──────────────── 보상 ◀───────────────────┘
```

| 단계 | 시점 | 플레이 |
|------|------|--------|
| 배치 | 3D 탑뷰 | 맵을 내려다보며 타워 설치·이동·판매, 적 경로와 사거리 확인 |
| 전투 | 1인칭 | 직접 이동·공격하며 자동 공격하는 타워와 연계해 웨이브 방어 |
| 마을 | — | 타워 영구 업그레이드, 플레이어 능력 강화 |

## 주요 기능 (계획)

- [ ] 탑뷰 ↔ 1인칭 카메라 전환
- [ ] 타워 배치 시스템 (사거리 미리보기)
- [ ] 적 경로 이동 및 웨이브 스폰
- [ ] 타워 자동 타겟팅·공격
- [ ] 1인칭 플레이어 이동·전투
- [ ] 기지 체력 / 승패 판정
- [ ] 마을: 타워 업그레이드, 플레이어 강화
- [ ] 세이브 / 로드

## 로드맵

1. **프로토타입**: 배치 → 전투 → 승패의 공통 코어 루프 *(진행 중)*
2. **수직 슬라이스**: 스테이지 1개 완성, 마을 시스템, 기본 아트·사운드
3. **콘텐츠 확장**: 타워·적·스테이지 추가, 밸런싱

## 실행 방법

1. Unity Hub에서 **Unity 6.4 이상** 설치
2. 저장소 클론 (Git LFS 필요)
   ```bash
   git lfs install
   git clone <repository-url>
   ```
3. Unity Hub → **Add project from disk** → 클론한 폴더 선택
